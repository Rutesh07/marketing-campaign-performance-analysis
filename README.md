# Marketing Campaign Performance Analysis

## Objective
Analyze multi-channel marketing campaign performance to identify high-ROI campaigns,
evaluate channel effectiveness, and support data-driven budget allocation.

## Dataset
Marketing Campaign Performance Dataset (Kaggle)

## Tools & Technologies
- Python (Pandas, NumPy, SciPy)
- MySQL
- Tableau

## Key Analysis Areas
- Campaign and channel performance KPIs
- ROI and acquisition cost analysis
- Statistical comparison across campaign types and channels
- Time-based performance trends
